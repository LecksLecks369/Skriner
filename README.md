# MetaScalp Screener — межбиржевой скринер рыночных неэффективностей

Самодостаточная копия проекта: Next.js 16 (App Router) + TypeScript + Tailwind 4 + shadcn/ui.
В комплекте уже лежат накопленные данные (`data/`) — журнал сигналов, история паттернов и серии метрик, поэтому после запуска z-score и статистика прогреваются мгновенно, без часа ожидания.

## Что внутри (страницы)

| Адрес | Что это |
|---|---|
| `/` | Скринер: топ-80 фьючерсов по обороту, межбиржевой спред, композитный скор 0–100, фильтры, модалка монеты |
| `/radar` | Режим «Радар» — большие карточки только сильных сигналов (для второго монитора) |
| `/liquidity` | «Неликвид»: глубина стакана, слипейдж $10k/$50k, Амихуд, max-позиция, метка «робот вошёл» |

Ключевые фичи: нетто-спред после комиссий, z-score спреда, возраст сигнала, сети вывода, cooldown алертов, мини-чарты, SSE-алерты в реальном времени, пресеты фильтров (JSON), ИИ-комментарий по монете, бэктест (кнопка «🧪 тест»), репутация монеты, базис спот×перпетуал, разброс фандинга + таймер выплат, китовая лента >$50k, CVD-прокси, корреляция с BTC, индекс страха&жадности и доминация BTC, конструктор алертов И/ИЛИ, webhook + Telegram, бумажные сделки, калькулятор позиции, горячие клавиши, вкладка «📈 История» (win-rate по 5 паттернам), JSONL-журнал сигналов.

## Быстрый старт (рекомендуется, через Bun)

Bun нужен, потому что скрипты `build`/`start` в package.json используют его кросс-платформенный шелл — это работает одинаково на Windows, macOS и Linux.

```bash
# 1. Установить Bun (один раз): https://bun.sh
curl -fsSL https://bun.sh/install | bash        # macOS / Linux
# Windows (PowerShell): powershell -c "irm bun.sh/install.ps1 | iex"

# 2. В папке проекта:
bun install        # зависимости
bun run build      # сборка (~1-2 мин)
bun start          # запуск на http://localhost:3000
```

Или просто: `./start.sh` (macOS/Linux) или `start.bat` (Windows) — сами проверят и поставят всё нужное.

## Альтернатива: Node.js (Linux / macOS)

```bash
npm install
npm run build
npm start
```

Требуется Node.js 20+. На Windows через npm не запускайте — используйте Bun (см. выше).

## Данные (важно)

Всё состояние живёт в папке **`data/`** — путь относительный, считается от папки запуска:

| Файл | Что хранит |
|---|---|
| `series.json` | Серии метрик (спред, объём, OI…) — прогрев z-score после рестарта |
| `signal_journal.jsonl` | Журнал сигналов с исходами — бэктест, win-rate, оптимизатор |
| `pattern_history.jsonl` / `pattern_outcomes.json` | История паттернов и их отработка |
| `snapshots.jsonl` | Снапшоты спредов (история для графиков) |
| `paper_trades.json` | Бумажные сделки |

- **Бэкап = скопировать папку `data/`.** Сейчас она весит ~26 МБ и растёт.
- Файлы сериализуются автоматически; при рестарте всё подхватывается с диска.
- Хотите стартовать с чистого листа — остановите сервер и удалите содержимое `data/`.

## Биржи

| Биржа | Статус | Нюансы |
|---|---|---|
| Bybit | ✓ | v5 API, стабильно |
| BingX | ✓ | **Обязательно** запрос с `User-Agent: Mozilla/5.0` (уже вшито в код) |
| OKX | ✓ | v5 API |
| Bitget | ✓ | v2 API |
| MEXC | ✗ | Отдаёт 403 с датацентровых IP; с домашнего/мобильного обычно работает — просто включается в UI |
| Ourbit | ✗ | Публичного API нет, заготовка в коде |

Все запросы идут через сервер (API-роуты Next.js) — CORS не мешает, ключи бирж не нужны: только публичные данные.

## Работа 24/7 на VPS

**Вариант 1 — pm2 (проще всего):**

```bash
npm i -g pm2 && pm2 start "bun .next/standalone/server.js" --name screener
pm2 save && pm2 startup        # автозапуск после ребута
```

**Вариант 2 — Docker (экспериментально, в комплекте Dockerfile):**

```bash
docker compose up -d --build
```

Папка `data/` монтируется как volume — статистика переживает пересборку контейнера.

**Вариант 3 — systemd:** создайте юнит, который делает `ExecStart=/usr/local/bin/bun .next/standalone/server.js` в папке проекта, `Restart=always`.

## Частые вопросы

- **После запуска таблица пустая первые секунды** — норма: первый скан занимает ~10–20 сек, дальше кэш 45 с.
- **z-score серый/«—»** — прогревает серии; с комплектным `data/series.json` готово почти сразу.
- **MEXC не включается** — 403 с серверного IP, см. таблицу бирж выше.
- **Алерты не приходят в Telegram** — настройки уведомлений: иконка 🔔 в шапке (chat id + токен бота).

Берите данные из скринера как гипотезы и проверяйте риск-менеджментом: нетто-спред уже считается с учётом taker-комиссий, но проскальзывание и глубину проверяйте во вкладке «Неликвид» перед входом.
